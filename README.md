# Zanzibaba Timber - Premium Pine Timber Supplier in Zanzibar

## SEO-First Bilingual Web App

### Features
- **Bilingual**: English/Kiswahili language toggle
- **Dark/Light Mode**: Auto-switching theme support
- **Mobile-First**: Responsive design with Tailwind CSS
- **SEO Optimized**: Dynamic metadata, sitemaps, schema markup
- **WhatsApp Integration**: Floating button + quote forms

### Pages
- `/` - Home with hero, popular sizes, quote form
- `/about` - Company information
- `/timber-sizes` - All timber dimensions (1x2, 1x3, 1x4, 1x6, 2x2, 2x3, 2x4, 2x6, 3x3, 4x4)
- `/timber-sizes/[size]` - Individual product pages with SEO
- `/prices` - Pricing table
- `/locations` - All Zanzibar delivery locations
- `/locations/[slug]` - Location-specific landing pages
- `/projects` - Completed projects portfolio
- `/hotel-supply` - Hotel & resort supply
- `/villa-supply` - Villa supply services
- `/government-supply` - Government & contractor supply
- `/wholesale` - Bulk pricing
- `/delivery` - Delivery information
- `/gallery` - Project images
- `/blog` - Timber tips & advice
- `/contact` - Contact form

### SEO Files
- `/public/sitemap.xml` - Main sitemap
- `/public/sitemap-products.xml` - Timber size sitemaps
- `/public/sitemap-locations.xml` - Location landing pages
- `/public/robots.txt` - Search crawler directives
- Schema markup on all pages (LocalBusiness, Product, FAQ)

### Setup
```bash
npm install
npm run dev
npm run build
```
